共 41 张。打开 index.html 查看分类索引，PNG 为原始窗口截图。

5 个主页面全部覆盖；设置较长，分顶部、中部、底部保留完整内容。另含详情、历史版本、筛选、搜索、空状态、新增/编辑/删除确认、独立项目选择窗口、深色主题和更新通知。

数据为隔离的示例账号；更新通知为示例状态。没有读取、改变真实账号或密码库，没有执行保存、删除、导入、导出或更新安装。
