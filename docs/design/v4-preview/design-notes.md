# LocalPass v4 · 待评审的 UI 草图

本目录是独立设计预览，不接入真实密码库，也不修改当前产品界面。图片中的账号和图标均为示例。网站名称、网页标签、地址与端口沿用现有数据模型。

## 设计意图

面向同时管理公网网站与内网服务的人：快速查找、区分端口、复制凭据。参考 Chrome 密码管理器的蓝白配色和导航，采用更紧凑的列表与详情并列布局。

- 领域：本地密码库、网站身份、账号、浏览器标签、端口、密码历史、复制保护。
- 色彩：浏览器纸白、浅灰蓝底色、选中态蓝、正文墨灰、加密状态绿；网站图标保留各自识别色。
- 特征：网站名 → 标签标题 → 完整地址的三级身份信息。同一 IP 的不同端口在列表和详情中一致显示。
- 避免：无用统计卡片、过宽留白、只用裸 IP 充当网站名称。

## 组件决策

整体：焦点为选中的网站及账号。导航 204px、列表 404px，详情使用剩余宽度；4px 间距基准，控件至少 40px，常规内边距 24px。

导航：保留密码、密码检查、设置三个入口；本地存储状态和锁定动作位于底部。灰蓝画布与内容连续，蓝色仅强调当前位置。

列表：名称 15px/600，地址 13px/400，最小 68px 行高；同一 IP 的端口与地址作为连续文本显示。选中态使用浅蓝底与蓝色文字，无额外装饰。

详情：网站名 28px/600，账号值 16px，字段标签 13px；用户名和密码共用白色容器，复制动作固定在右侧。网站信息独立成组，保持标签与值对齐。

弹窗：沿用相同字体、颜色与控件，主操作置底，网站和端口分开编辑。无生产保存行为。

字体：Segoe UI、Microsoft YaHei UI，沿用 Windows 原生观感与本地字体；技术地址使用等宽字体以方便辨认。

层次：灰蓝画布、白色内容、略深输入底色；分隔线为低对比灰，无装饰渐变或重阴影。层级主要来自字号、字重、间距与表面色差。

- `edit-dialog.png`：编辑弹窗设计图。

预览按钮仅演示设计；不会复制真实凭据、打开网站或写入密码库。
