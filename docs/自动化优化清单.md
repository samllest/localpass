# LocalPass 自动化优化清单

更新日期：2026-10-26

目标：用户正常浏览、登录、注册即可完成账号保存和维护。网站图标、连接恢复、失败重试和备份由程序处理。界面提供查看和管理入口，日常保存不依赖手动点击。主密码解锁属于必要的密码库访问验证。

## 发布衔接

桌面端 1.5.1 与扩展 1.4.1 已于 2026-10-26 发布到内网下载站，包含本表的已完成项目、开机自启状态校验修复及网页账号浮层优化。两端需要配套安装；扩展分发 ZIP 不包含本机连接密钥，必须由桌面端管理扩展目录并写入密钥。内网更新索引、真实更新器下载及 SHA512 校验已通过，旧版本安装包继续保留。

扩展 1.4.2 独立更新修复 SPA 登录表单及项目名称延迟加载时漏掉账号选择的问题，与桌面端 1.5.1 兼容。表单就绪后自动补查仍聚焦的输入框，关闭或填充后不会因页面更新重新弹出。

## 已知边界

网站没有提供有效图标、暂时不可达或所有来源均被拦截时，程序保留已有默认头像并后台重试；不能保证任何网站都能取得真实图标。不得把第三方图标服务作为内网站点的自动兜底，以免将内网地址发送给外部服务。

自动化不能以误覆盖密码或跳过密码库身份验证为代价。匹配不明确时优先保留记录；需要用户处理的失败应提示原因，普通重试和无变化状态保持安静。
