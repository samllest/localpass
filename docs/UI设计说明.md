# LocalPass UI 设计说明

## v4 · 已确认效果图落地（2026-10-19）

本轮以 `docs/design/v4-preview/overview.png` 和 `edit-dialog.png` 为视觉参考，将真实密码库界面调整为导航、网站列表、账号详情三栏。效果图是示例数据，实际界面显示密码库中保存的网站图标和名称，缺少图标时回退到名称首字。

- 1100px 以上：侧栏 204px、网站列表 404px，详情占剩余空间；1280px 以下分别收紧为 180px 和 348px。搜索与列表始终可用，选择网站在右侧展示详情。
- 1100px 及以下：列表与详情切换，返回后恢复列表滚动位置和所选网站焦点。850px 以下侧栏收为图标，620px 以下导航移到顶部。
- 桌面初始选中首个匹配项；搜索或分类过滤掉当前记录时同步更新详情。批量选择期间显示管理提示，避免对其他账号误操作。
- 网站名称作为主标题、网页标签作为辅助信息；列表、详情与链接完整显示地址及端口，并在地址中强调端口。同 IP 不同端口保留独立记录。
- 单账号编辑位于详情顶部，添加账号和删除位于「更多操作」；多账号保留每个账号的编辑、删除和历史版本入口。
- 编辑弹窗显示网站摘要，名称与类型、地址与端口分别排列。密码留空保留原密码；保留强密码生成、错误重试、保存中状态和原生 dialog 键盘行为。
- 字体与间距使用现有全局 Token，4px 间距基准，列表最小行高 68px；图标统一到 24px 画布与描边粗细。深色主题使用相同组件结构。
- 密码显示与历史密码显示仍在 30 秒后、窗口失焦、切换网站或账号操作时收起；复制仍走主进程的剪贴板保护。

验证：生产构建和 17 项现有测试通过；隔离浏览器使用模拟 IPC 验证编辑、端口、真实 PNG 解码、多账号、复制、失焦隐藏、历史重试、删除确认、批量选择、主题、检查页跳转、备份入口、保存失败恢复、窄屏返回及长文本。1440 / 1280 / 1100 / 1080 / 768 / 390px 下无横向溢出。验证未读取真实密码库。

## v3 · 参考 Chrome 密码管理器（2026-10-19）

v3 实现参考 Chrome 的信息结构与操作习惯：顶部搜索、左侧「密码 / 密码检查 / 设置」、网站聚合列表，以及独立的账号详情页。以下内容作为历史记录保留，当前以 v4 和代码为准。

### 界面与交互

- 浅色为新用户默认主题；保留已有主题偏好，支持深色和跟随系统。主题在解锁页加载时即应用。
- 搜索名称、网站和用户名，不搜索密码；匹配某个用户名时保留网站的全部账号。筛选和排序在完整本地列表上执行，不影响密码检查统计。
- 网站 / 应用筛选、名称 / 最近更新排序；最近更新取同组全部账号中的最新时间，SQLite 无时区日期按 UTC 解析。
- 点开记录进入完整详情，返回保留列表滚动位置和键盘焦点；Ctrl/Cmd+K 聚焦搜索，Escape 返回列表。
- 新增和编辑使用原生 dialog，支持焦点约束、Escape 关闭、关闭后恢复焦点，保存失败保留输入。
- 当前密码和历史密码默认隐藏；详情中显式显示的密码在 30 秒后或窗口失焦时隐藏。复制沿用主进程的 30 秒剪贴板清除。
- 单账号和批量删除都有确认，明确账号数量以及历史版本一起删除。部分删除失败时保留未删除项目供重试；过滤后的隐藏项不会继续被选中。
- 添加网站时将 URL 规范化为域名及端口；localhost 和内网地址支持端口。外部链接仅允许 HTTP(S)。
- 「密码检查」展示重复和强度不足的具体账号，没有虚构评分。检查完全在本机进行，不包含在线泄露数据库查询。
- 「设置」提供主题、剪贴板保护说明、已有加密备份导入导出入口，以及 Chrome 扩展安装步骤。当前加密备份需要原密码库的密钥，不支持跨独立密码库恢复或 Chrome CSV 导入。
- 原先未接入的收藏、标签、备注等占位按钮从当前页面移除。

### 设计规则

- 主操作是找账号：搜索和网站列表占据主要区域，检查提示作为次要入口；不在列表上重复展示隐藏密码。
- 页面采用灰白 / 深灰表面和单一蓝色操作强调；警告、错误、成功使用语义色。
- 字体使用本机 Segoe UI / 微软雅黑 / PingFang，无网络字体依赖；密码使用等宽字体。
- Token 集中在 `src/renderer/src/assets/main.css`，包括颜色、4px 间距基准、字号、控件高度和布局宽度。
- 桌面侧栏 256px，主内容最大宽度 856px；620px 以下导航移到顶部，详情和弹窗仍可操作。
- 共用 `UiIcon`、`VaultDialog` 和控件类，`PasswordDetails` 独立维护敏感字段显示和历史加载状态。
- 使用 Web Crypto `getRandomValues` 生成密码，拒绝采样避免取模偏差，并确保包含大小写字母、数字和符号。

### 本轮验证

- `npm run build`：Electron 主进程、预加载和 Vue renderer 构建通过。
- `npm test`：9 项测试通过，覆盖加密、分组搜索、完整检查统计、时间排序、生成器和安全 URL。
- 新增与重构的主要 Vue 组件及工具通过 ESLint 检查。
- 使用生产构建在隔离的无头 Chrome 中验证；IPC 使用内存模拟，只包含模拟账号。
- 已验证新增、编辑保留原密码、生成强密码、复制、历史记录、保存/删除/历史读取失败恢复、批量选择、主题、备份入口、键盘操作、空状态和超长文本。
- 列表在 1440 / 1080 / 768 / 390px 下检查，详情和弹窗在窄屏下检查，无横向溢出；浏览器运行时错误为 0。
- 预览和临时验证脚本保存在 `out/ui-qa/`。这些结果验证 renderer 交互，不代替真实 Electron 原生文件对话框、系统剪贴板、扩展端到端集成测试。

## 1. 设计目标与原则

| 原则 | 落地方式 |
|---|---|
| 现代简洁 | 中性色表面 + 单一品牌蓝，去掉旧版渐变、发光、双层叠加样式 |
| 风格一致 | 全部颜色/圆角/阴影/字号收敛为 Design Token，组件只用 Token，不允许硬编码色值 |
| 安全感 | 密码管理器需要"可信、稳重"的气质：低饱和深蓝灰 + 高对比正文 |
| 可用性优先 | 密码/账号是核心信息，列表行高 ≥ 56px，操作按钮 ≥ 30px 命中区 |

## 2. 现状分析

### 2.1 页面结构与交互流程

```
App.vue（无框窗口 + 自绘标题栏）
├─ UnlockScreen   解锁/注册（用户名 + 主密码）
└─ MainView       主工作台
   ├─ Sidebar     分类导航（全部/网站/应用/其他/最近）+ 锁定
   ├─ Topbar      搜索 + 安全检查/设置/主题/通知
   ├─ Records     标题 + 添加/批量/导入导出 + 分类 pills + 记录表格
   └─ DetailPane  选中记录的详情（账号/密码/网站/标签/备注/删除）
侧滑面板：安全检查、设置、通知；居中弹窗：新增/编辑账号
```

交互流：解锁 → 浏览分类/搜索 → 点选记录 → 详情查看与复制（复制后 30s 清剪贴板）→ 新增/编辑/删除 → 锁定。

### 2.2 现有 UI 的问题

1. **两代样式叠加**：`main.css` 先定义了一套青色（#66c4df）体系，后被"vault-workspace"深蓝（#071a33 / #1481f4）整层覆盖，浅色主题又用 20+ 条 `html[data-theme='light']` 逐类覆盖——同一语义色有 3 处来源，改一个颜色要动多处。
2. **品牌色不统一**：解锁页/弹窗残留紫色渐变（#8b5cf6），主界面是蓝色。
3. **响应式断层**：780px 以下详情面板直接 `display:none`，选中记录后无任何反馈路径；侧边导航占宽不变。
4. **网络字体依赖**：`@import Google Fonts`（IBM Plex Sans）在离线 Electron 环境下静默失败，实际渲染不稳定。
5. **死代码**：`base.css`、`PasswordCard.vue`、`Versions.vue` 未被任何入口引用（建议后续删除，本次未动）。

## 3. 整体布局

桌面端（≥1200px）三栏工作台：

```
┌────────────── 标题栏 46px ──────────────┐
│ Sidebar 232px │ Topbar 60px（搜索+操作） │
│ 分类导航      ├──────────────────────────┤
│ 本地存储提示  │ 记录区（弹性） │ 详情 360px│
│ 锁定按钮      │ 工具栏/表格      │ (可滚动) │
└─────────────────────────────────────────┘
```

### 响应式断点（3 档）

| 断点 | 布局策略 |
|---|---|
| ≥1200px | 三栏：侧边导航 232px + 列表 + 详情侧栏 360px 常驻 |
| 900–1200px | 详情变为**右侧浮动抽屉**（fixed，z-index 80，带投影），头部出现关闭按钮 |
| <900px | 侧边导航隐藏，由列表区"分类 pills"承担筛选；表格隐藏密码/时间两列；640px 以下工具栏换行、抽屉全宽 |

## 6. 字体排版

- **字体栈（去网络依赖）**：`system-ui, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`，英文数字走系统 UI 字体，中文自动回落苹方/雅黑。
- **等宽**：`'Cascadia Mono', Consolas, monospace`——仅用于密码值，明示"这是敏感数据"。
- **基础字号 14px，行高 1.5**；字重仅用 400 / 500 / 600 / 650 / 700 五档。
- 数字（计数徽标、时间）启用 `font-variant-numeric: tabular-nums` 对齐。

## 7. 间距 / 圆角 / 阴影 / 动效

- **间距**：4px 基数。控件内边距 8/12，组件间距 16，区块间距 20–24，页面留白 24。
- **圆角**：控件 `8px`（`--radius-s`）、卡片/表格 `12px`（`--radius`）、弹窗 `16px`（`--radius-l`）、胶囊 `999px`。
- **阴影**：三档 Token——`--shadow-xs`（卡片静置）、`--shadow-sm`（卡片 hover / 抽屉）、`--shadow-md`（弹窗 / 通知）。
- **动效**：统一 `160ms ease-out`（`--ease`），仅作用于颜色/透明度/1px 位移；激活态 `scale(0.98)` 反馈；尊重 `prefers-reduced-motion`。

## 8. 核心组件规范

### 8.1 按钮

| 组件 | 样式 |
|---|---|
| 主按钮（解锁/添加/保存） | 实心 `--accent`，白字，8px 圆角，hover 提亮 + 上移 1px，active `scale(0.98)` |
| 次级按钮（批量/导入导出） | 描边 `--border-strong` + `--bg-2` 底，激活态切 `--accent-soft` |
| 图标按钮（top-icon / icon-btn） | 30–32px 方形命中区，hover `--bg-2`，全站统一 `:focus-visible` 焦点环 |
| 危险按钮（锁定/删除） | 默认描边幽灵态，hover 才浮现 `--danger` 底色，避免误触视觉噪音 |

### 8.2 输入框

1.5px 描边 + `--bg-2` 底；聚焦时描边转 `--accent` 并叠加 3px `--accent-soft` 焦点环；错误态 `--danger`。密码强度条 4px 高、五级色阶（红→绿）沿用。

### 8.3 导航（侧边栏）

- 导航项：44px 高、8px 圆角、左图标右计数徽标；激活态 `--accent-soft` 底 + `--accent` 文字（不再用大面积实心蓝块，降低噪音）。
- 分组标题：11px 大写、0.08em 字距、`--text-3`。
- 底部"本地加密存储"提示卡 + 锁定按钮。

### 8.4 记录表格

- 表头 40px / 行高 56px，网格列：`28px 选择框 + 1.6fr 名称 + 1fr 账号 + 0.7fr 密码 + 0.8fr 时间 + 24px`。
- 行 hover `--bg-2`，选中 `--accent-soft` + 内描边 `--accent`；批量勾选行叠加半透明 accent 底。
- 首列彩色首字头像（36px、10px 圆角）承接视觉锚点。

### 8.5 详情面板 / 抽屉

- 字段行统一 `56px` 栅格（标签 64px + 值 + 操作按钮），分隔线用 `--border`。
- 主操作（复制密码）实心蓝、次操作（编辑）描边；删除记录为通宽危险幽灵按钮，置于面板最底部并与内容拉开 24px。

### 8.6 弹窗 / 侧滑面板 / Toast

- 弹窗 480px、16px 圆角、`--shadow-md`，遮罩 `rgba(0,0,0,.55)` + 轻模糊。
- 安全检查/设置为右侧 400px 面板，安全评分环保留但颜色走语义 Token。
- Toast 底部居中，成功/错误用语义色 12% 底 + 同色描边。

## 9. 可用性与可达性

1. 全局 `:focus-visible` 焦点环（键盘可达）。
2. 交互命中区 ≥ 30px，表格行整行可点。
3. `prefers-reduced-motion` 下关闭位移/缩放动画。
4. 深浅主题共用一套组件 Token，切换主题零样式漂移。
